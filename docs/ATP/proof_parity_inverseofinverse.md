# Proof-object parity, easy case

`AbelianGroupAxioms / InverseOfInverse` -- 4 axioms, 1-conjunct
goal, smallest non-trivial case from the comparator batch.

Side-by-side TFindProof datasets, generated by
`/tmp/parity_inverseofinverse.wls`:

## Internal: Method -> "VampireUEQ"

```
{Axiom, 1..4}                            -- assoc, comm, id, inv
{Hypothesis, 1}                          -- the negated conjecture
{CriticalPairLemma, 1} <- {A, 1} + {A, 4}
{CriticalPairLemma, 2} <- {A, 3} + {A, 2}
{SubstitutionLemma, 1} <- {CPL, 2} + {CPL, 1}
{CriticalPairLemma, 3} <- {SL, 1} + {A, 4}
{SubstitutionLemma, 2} <- {A, 3} + {CPL, 3}
{Conclusion, 1}        <- {SL, 2} + {Hypothesis, 1}
```

Total: 4 + 1 + 3 + 2 + 1 = 11 constructs.

## External: Method -> "VampireProcess"

```
{Axiom, 1..4}                            -- same axioms (different numbering)
{Hypothesis, 1}                          -- same negated conjecture
{CriticalPairLemma, 1} <- {A, 3} + {A, 2}    [<-- == internal CPL 2 ]
{CriticalPairLemma, 2} <- {A, 1} + {A, 4}    [<-- == internal CPL 1 ]
{SubstitutionLemma, 1} <- {CPL, 1} + {CPL, 2}
{CriticalPairLemma, 3} <- {SL, 1} + {A, 4}
{SubstitutionLemma, 2} <- {A, 3} + {CPL, 3}
{CriticalPairLemma, 4} <- {Hypothesis, 1} + {SL, 2}
{Conclusion, 1}        <- {CPL, 4}
```

Total: 4 + 1 + 4 + 2 + 1 = 12 constructs.

## Diff

The two proofs are STRUCTURALLY THE SAME modulo two cosmetic
discrepancies:

1. **CPL numbering swap.**  Internal generates
   `(A1, A4) -> CPL_1` first, then `(A3, A2) -> CPL_2`.  External
   generates the same two superpositions in the reverse order.
   The lemmas themselves (`and(e, X) = X` and the assoc-of-inverse
   form) ARE IDENTICAL.  This is heap-pop order, NOT a real
   structural difference.

2. **Final-step segmentation.**  External records two final steps:
   `CPL_4 = superposition(Hypothesis, SL_2)` followed by
   `Conclusion = trivial_inequality_removal(CPL_4)`.  Internal
   collapses both into a single `Conclusion = (SL_2, Hyp_1)` --
   the contradiction is derived in one shot rather than two.
   Equivalent under the obvious fold `superposition_with_goal +
   trivial_inequality_removal -> Conclusion`.

Apart from these two symmetries, **the proofs are byte-identical**:

* same 4 axiom set (CircleTimes-assoc, CircleTimes-comm,
  CircleTimes-identity, CircleTimes-inverse);
* same negated goal `not[not[skc1[]]] != skc1[]`;
* same 2 critical-pair lemmas (just relabeled);
* same forward-demodulation chain `SL_1 <- CPL_2 -> CPL_3`
  then `SL_2 <- A_3 -> CPL_3`;
* same closure of the empty clause.

## What "full identity" requires

For the comparator to report `proofs identical? True` on this case
without manual inspection, two folds need to land in
`tools/baselines/compare_methods.wls` / `ProcessProofObject.wl`:

1. **Canonicalize CPL labels** by structural ordering of the
   underlying lemma (e.g. sort by some normal form of the
   `Statement` field) BEFORE numbering.  Eliminates the heap-pop
   numbering noise.
2. **Fold the final superposition-with-goal + trivial-inequality-
   removal pair** into a single Conclusion at SZS-import time.
   Mirrors what the internal proof already does.

Both are pure-WL post-processing -- no engine change needed.
Once shipped, this case (and the other "thvm one-superposition-
short" cases in the 8-row batch) should collapse to
`proofs identical? True`.

The 1-superposition gap reported by `compare_proof_shape.wls`
(`port 3 vs ref 4 superpositions, delta -1`) is the same finding
in aggregate form: it's the `CPL_4` step that the internal proof
folds.
