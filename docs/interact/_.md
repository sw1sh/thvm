# Interactions

Each rule lives in its own file under [src/interact/](../../src/interact/)
and has a matching markdown page here. The C file's leading comment
mirrors the sequent rule from the doc; if they disagree, the doc wins
and the comment needs updating.

## Stuck pairs (deferred)

These show up when the WNF reducer pops a frame and finds an active
pair with no matching interaction. The reducer puts the WHNF back
into the original heap cell and treats the frame itself as the new
WHNF, so the result is a well-formed but unreduced node.

- DP0,1 / LAM (clone the lambda)
- DP0,1 / SUP with different labels (commute)
- APP / SUP (commute)

A test that exercises one of these will drive its implementation.

## Counting interactions

Each rule increments the global `ITRS` counter exactly once when it
fires. C tests assert the delta:

```c
u64 before = ITRS;
Term out = wnf(some_term);
CHECK_EQ(ITRS - before, expected_count);
```

WL tests do the same via `TItrs[]`.
