## Unreleased

### Runtime
- Tensor.transpose() and .T swap dims 0 and 1, as tinygrad's do (mixin/movement.py:323-343); they swapped the last two, which differs from 3-D up (every in-tree caller is 2-D). gelu(approximate="none") is the erf form, with tinygrad's erf ported (mixin/elementwise.py:780-795, 1059-1071), and an unknown mode raises; it was always the tanh form. max_pool2d(ceil_mode=True) raises when a window would start past the input (the -inf pad is not wired) instead of silently rounding down. Tests: test_tensor_surface_sync.
- The CPU end-of-realize arena-view clear keeps the preserve bit of a parent from an earlier realize (a held weight a matmul view reads), as CUDA's has since the Krea weight-zeroing fix; it cleared it, so the rollback could recycle a live weight. Test: test_cpu_free_list.
- wnf/pool.c's unused WnfPoolWorkerArg is removed.
- helpers.fetch(gunzip=True) stores the decompressed body, under a .gunzip cache name, as tinygrad does (helpers.py:476-484); it took the flag and kept the gzip bytes. Test: test_nn_bookkeeping.
- nn.BatchNorm counts its training batches in num_batches_tracked, as tinygrad does (nn/__init__.py:58); it stayed 0. Test: test_nn_bookkeeping.
- nf uses a step session only when it opened one: with the WL stepper's session open it ran on that session and detached it. At T=1 it re-enumerates when its seed was clamped to the bag or a push found the bag full (now dropped and counted instead of spinning forever with no thief), so redexes past the 2^18 seed slots fire. Tests: test_nf_pool.
- eval_collapse reuses popped queue slots, so it stops early only when 65536 tasks are pending at once: it stopped after 65536 pushes in all, at 32767 leaves of a long SUP comb. Test: test_cnf.
- LAM_ERA_MASK is set only on lambdas whose binder is unused: APP-BRI's inner lambda (its $k is read by the ANN outside the body) and ANN-LAM's new lambda (read through the bridge that replaces the old binder) were sealed as erasable, so applying them dropped the argument. The binder-use walk and auto-dup's use collection size nodes with term_cells, so a use under a DSU, a STORE or any UOp missing from their own arity table counts (auto-dup left such uses without a DUP). Tests: test_icc.

- CheckProof reads functors wider than 16 arguments by currying them into
  a binary application symbol, records and problem alike; every proof of
  TOP052-1, whose goal is a 144-argument tuple, was Unknown.  A model of
  the original gives one of the curried form only when it can host the
  partial applications (a satisfiable Horn set always has such a model),
