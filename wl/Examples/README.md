# wl/Examples

Runnable example terms, one folder per example. Each folder has:

- `term.wl` -- a minimal WL file whose final value is the term to
  render. No `Needs[...]`, no `TInit[]`, no boilerplate. The runner
  handles all of that.
- `graph.png` -- the corresponding `THeapGraph[term]` snapshot,
  regenerated by [run.wls](run.wls).

To regenerate every PNG:

```sh
make wl-examples                         # all of them
make wl-examples EXAMPLE=02-id-app-era   # just one
```

Or directly:

```sh
wolframscript -f wl/Examples/run.wls
wolframscript -f wl/Examples/run.wls 07-dup-sup-annihilate-pre
wolframscript -f wl/Examples/run.wls 07-dup-sup-annihilate-pre --eval
```

`--eval` runs the example without writing any PNG -- useful when you
just want to see what the WL evaluator returns.

## Adding an example

1. Create a new folder (next sequential number, hyphenated name).
2. Drop a `term.wl` whose last expression is the term to render.
   Use `TFreshLabel`-backed `TSup[a, b]` / `TDup[body, k]` unless you
   specifically need an explicit label.
3. Run `make wl-examples EXAMPLE=<your-folder>` to generate the PNG.
4. (Optional) reference the new PNG from `docs/heap_graph.md`.

If a graph turns out to need both projections of a `TDup`, return them
as a list (`{dp0, dp1}`) -- the runner forwards the list to
`THeapGraph[ts_List]` so both seeds are honored.
