## Usage

<code>[TVoiceStyleData]()[]</code> gives the voices of a text-to-speech model run by thvm.

<code>[TVoiceStyleData]()["*voice*"]</code> gives the properties of the voice named *voice*.

<code>[TVoiceStyleData]()["*voice*", "*prop*"]</code> gives the property *prop* of the voice.

## Details & Options

- [TVoiceStyleData]() is shaped after the built-in [VoiceStyleData](): a voice is an association, and its `"Name"` is what `$VoiceStyles` lists.
- A voice's name is what the `"Voice"` option of [TSpeechSynthesize](), [TSpeak]() and [PhononSynthesize]() takes; the case of its letters does not matter.
- The [Method]() option chooses the model. `"Phonon"`, the default, has the 37 English voices of the catalogue that the makers of Phonon publish for it: 12 American, 13 British and 12 characters.
- A voice has these properties:

  | | |
  | --- | --- |
  | `"Name"` | the name of the voice |
  | `"Language"` | the language it speaks |
  | `"LanguageCode"` | the language with its region, such as `"en-GB"` |
  | `"Gender"` | `"Female"`, `"Male"`, or [Missing]() for a character |
  | `"Age"` | the age the voice sounds, such as `"Adult"`, or [Missing]() |
  | `"Description"` | the catalogue's description of the voice |

- Listing the voices fetches nothing; a voice's file, a quarter of a megabyte, is fetched the first time speech is synthesized in it.

## Basic Examples

One voice:

```wl
#| eval: false
TVoiceStyleData["Hugh"]
```

<!-- => an association with "Name" -> "Hugh", "Language" -> "English", "LanguageCode" -> "en-GB", "Gender" -> "Male", an age and a description -->

---

The names of the voices:

```wl
#| eval: false
TVoiceStyleData[][[All, "Name"]]
```

<!-- => a list of 37 names, from "Zoey" to "Fairy Godmother" -->

## Scope

One property of a voice:

```wl
#| eval: false
TVoiceStyleData["Maeve", "Description"]
```

<!-- => a sentence that describes the voice -->

---

The British female voices:

```wl
#| eval: false
Select[TVoiceStyleData[], #LanguageCode == "en-GB" && #Gender == "Female" &][[All, "Name"]]
```

<!-- => a list of 7 names -->

## Applications

Speak a sentence in every character voice:

```wl
#| eval: false
Scan[TSpeak["Who goes there?", "Voice" -> #] &, Select[TVoiceStyleData[], MissingQ[#Gender] &][[All, "Name"]]]
```

<!-- => the sentence is spoken twelve times, each in another voice -->

## Possible Issues

A name that is not a voice gives a failure:

```wl
#| eval: false
TVoiceStyleData["Nobody"]
```

<!-- => the message TVoiceStyleData::voice is issued and the result is a Failure -->
